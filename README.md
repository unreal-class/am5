# AM5 테니스 경기 관리

AM5 동호회의 출석, 복식 대진표 자동 생성, 경기 시작/종료/결과 입력, 개인 전적, 월간/연간/전체 랭킹을 관리하는 **모바일 우선 웹 서비스**입니다.

## 기술 구성

- **Next.js** (App Router, TypeScript)
- **Supabase** (Auth + PostgreSQL, RLS)
- **Vercel** 배포

## 주요 기능

- 회원가입 / 로그인 (초기 비밀번호 `AM5AM5`, 첫 로그인 시 변경 강제)
- 출석 / 퇴장 (당일 모임 자동 생성)
- 출석자 + 가용 코트 기준 **복식 대진 자동 생성**
- 경기 시작 / 종료 기록, 점수 입력, 승패 저장
- 개인 승 / 패 / 승률 및 **월간 / 연간 / 전체 랭킹**
- **관리자 전용**
  - 회원 조회, 수정, 권한 부여, 비밀번호 초기화, 삭제
  - 가용 코트 대여 시작 / 종료
  - 경기 기록 삭제 (개별 / 일괄)
  - 테스트 콘솔

## 경기 배정 규칙

### 배정 대상
- 오늘 모임에 출석 중이고 퇴장하지 않은 회원
- 현재 진행 중 / 예정된 경기가 없는 회원
- 가용 코트가 있고 대기 인원 4명 이상일 때 배정

### 배정 우선순위
배정 가능한 선수 중 한 명이라도 오늘 경기 수가 3경기 미만이면 아래 순서를 기본 원칙으로 사용합니다.

| 순위 | 기준 | 방향 |
|------|------|------|
| 1 | 오늘 경기 횟수 | 적은 사람 우선 |
| 2 | 대기 시간 (출석 후 경과) | 긴 사람 우선 |
| 3 | 출석 시간 | 빠른 사람 우선 |

배정 가능한 모든 선수의 오늘 경기 수가 3경기 이상이면 경기 수와 대기시간 대신 출석 시간이 빠른 상위 4명을 우선 배정합니다.

### 팀 분배 우선순위
선정된 4명을 A팀 / B팀으로 나눌 때 아래 순서로 최적 조합을 찾습니다.

| 순위 | 기준 | 설명 |
|------|------|------|
| 1 | 남녀 혼성 | 여성 인원이 있으면 각 팀이 남성+여성 조합 |
| 2 | 승률 균형 | A팀과 B팀 평균 승률 차이 최소화 |
| 3 | 파트너 중복 회피 | 같은 팀 경험 조합 최대한 회피 |

### 생성 수
`min(가용 코트 수, ⌊대기 인원 ÷ 4⌋)` 만큼의 경기가 한 번에 생성됩니다.

## 기본 관리자 계정

Supabase 환경 변수가 설정된 상태로 앱에 접속하면 자동 생성됩니다.

- 아이디: `admin`
- 초기 비밀번호: `AM5AM5`

운영 배포 후 **반드시 즉시 로그인하여 비밀번호를 변경**하세요.

## 관리자 추가 지정

관리자 화면 > 회원 관리에서 권한을 변경하거나 SQL Editor에서 직접 실행:

```sql
update public.profiles set role = 'admin' where login_id = '회원이름';
```
